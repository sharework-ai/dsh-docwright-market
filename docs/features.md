# 功能与业务规则

市场连接三方的场景包(pack)生态:**作者**投稿场景包、**审核员**把关质量、
**消费者**一键安装到自己的 docwright。全部能力围绕一条流水线:
投稿 → 机器校验 → 人工审核 → 发布 → 安装。

## 角色

| 角色 | 入口 | 能做什么 |
|---|---|---|
| 作者 | `/submit.html` + `/account.html` | 注册/登录(先设组织)后上传 pack 压缩包,实时看到机器校验报告;管理自己的 pack(改元数据/下架/恢复/删除)、查投稿历史、撤回待审投稿、改密码 |
| 审核员 | `/admin.html` | 查看待审队列(报告 + 文件树 + functions.js 高亮),通过/拒绝并附备注 |
| 消费者 | `/` + `install.mjs` | 浏览/搜索目录,按 pack 名安装最新版,或 `name@version` 钉版安装历史版本 |

## 投稿流水线

1. **投稿**:作者在 `/submit.html` 上传 pack 目录的 `.tgz`(≤ 50 MB),填
   author(显示名)/ category / license(SPDX 白名单)/ homepage(可选)。
   **投稿前账号必须已设置发布者组织**(见"账号与权限"),否则 403。
2. **机器校验**(立即执行):校验 sidecar 解包(防路径穿越)→ 市场形状检查 →
   spawn docwright 的 `pack:check`(golden 全绿 = 通过)。校验失败即刻返回
   报告,**不落任何存储**;通过才进入待审队列。
3. **人工审核**:审核员看到机器报告与 pack 内容;通过 = 立即发布
   (tarball 入 Storage 公开桶 + 目录表 upsert + **版本历史追加** +
   **发布者组织盖章**);拒绝 = 归档决策与备注。
4. **安装**:消费端脚本下载 tarball、双重完整性校验、原子落盘进 packsDir。

## 机器强制规则(服务端,不可绕过)

| 规则 | 违反后果 |
|---|---|
| `manifest.name` 必须 kebab-case(`^[a-z0-9][a-z0-9-]*$`)且目录名一致 | 拒收 |
| 不与 docwright 内置六 pack(cosmic-*)重名(同名会覆盖内置) | 拒收 |
| packs/ 内游离文件/目录(每个子目录必须是合法 pack) | 拒收 |
| pack:check golden 全绿(每语言) | 不过审不进队列 |
| 投稿账号必须已设置发布者组织 | 403 |
| 同名待审中只允许一个投稿 | 409 |
| (name, version) 组合全历史唯一(**删除 pack 也不释放**) | 409 |
| 更新必须来自原作者账号 | 403 |
| 更新版本必须严格递增(semver,含 pre-release 排序) | 409 |
| 内容哈希必须变化(纯 bump 版本不算更新) | 409 |

## 人工审核的安全边界

`rules/functions.js` 是可执行 JS,在每个用户的 docwright 装载 pack 时执行。
机器校验会执行它(校验需要),但**上架前必须有人读过代码**:审核页强制展示
文件树与源码;站点与 index 对含函数规则的 pack 打 `hasFunctionRules` 披露标;
投稿指南要求作者说明其用途。安装器只复制字节(sha256 + 内容哈希双重校验),
永不执行 pack 内容。

## 账号与权限

- 注册仅需邮箱+密码(自托管实例 AUTOCONFIRM,无邮件依赖);作者身份 = 账号,
  不需要 git/GitHub。密码修改在 `/account.html` 浏览器侧完成(先验当前密码,
  再经 GoTrue `PUT /auth/v1/user` 轮换),无需服务端参与。
- 管理员 = `profiles.is_admin = true` 的账号(首任管理员由部署者手工指定,
  见部署文档)。管理员的权力仅限审核队列;pack 的属主操作与管理员无关。
- **发布者组织**:每个账号可设置一个 org(小写 kebab-case,全局唯一,
  少量保留名不可用)。组织是发布者身份,展示在列表/详情/index;投稿前必须
  设置。**修改组织是账号页上的一个独立操作**:一次事务内改 profiles 并把该
  账号名下全部 pack 一并改标,UI 先展示受影响的 pack 数再确认。
- 投稿的**属主账号**在首次发布时锁定;后续更新必须同账号(防冒名)。
- **属主管理**(`/api/my/*`,属主限定):改元数据(category/license/homepage/
  author;description 与 manifest 绑定,只能随新版本投稿更新)、下架/恢复、
  硬删、撤回待审投稿。**下架** = 从目录/index 隐藏、tarball 下载返回 410、
  可随时恢复;下架期间审核通过的新版本不会自动恢复上架。**硬删** = 目录行 +
  版本历史 + Storage tarball 一并移除,名字释放可重注册,但 submissions 历史
  保留——同名同版本号永久不可复用,重发必须提升版本号。
- **版本历史**:每个通过的发布在 `pack_versions` 追加一行;全部历史版本的
  tarball 均可下载,详情页列版本清单,`install.mjs name@version` 钉版安装
  (缺省装最新)。
